Sample HRV Data Files - Format Notes
=====================================
All files are SYNTHETIC but follow documented format specifications.
Created for parser testing. RR values are physiologically realistic
(~785-891 ms, corresponding to ~67-76 bpm).

1. POLAR (data/demo/polar/)
---------------------------

a) polar_h10_rr_sample.csv
   - Source format: Polar Beat / Polar Sensor Logger CSV export
   - Separator: comma
   - Columns: "Phone timestamp" (ISO datetime with ms), "RR-interval [ms]" (integer ms)
   - Units: milliseconds
   - Reference: Polar Beat app export, ECG Logger app, Polar Sensor Logger

b) polar_flow_hrv_export.csv
   - Source format: Polar Flow web service HRV export (headerless TSV)
   - Separator: tab
   - Columns: elapsed_time_seconds (float), RR_interval_ms (integer)
   - Units: seconds (col 1), milliseconds (col 2)
   - No header row
   - Reference: https://github.com/oroce/polar-h7-rr, Polar Flow web export

2. EMPATICA E4 (data/demo/empatica/)
-------------------------------------

IBI.csv
   - Source format: Empatica E4 Connect IBI export
   - Separator: comma + space (", ")
   - Line 1 (header): Unix timestamp of recording start, " IBI"
     Example: "1775181600.000000, IBI"
   - Data lines: time_offset_seconds, ibi_duration_seconds
   - Units: seconds (both columns, float at 1/64s resolution)
   - Gaps in data indicate periods where BVP signal was unclear
   - To convert to ms: multiply by 1000
   - Reference: https://support.empatica.com/hc/en-us/articles/201608896

3. ELITE HRV (data/demo/elite_hrv/)
-------------------------------------

rr_intervals.txt
   - Source format: Elite HRV app raw export
   - One RR interval per line, no header
   - Units: milliseconds (integer)
   - No timestamps (only reading start time is in filename)
   - Filename convention: "YYYY-MM-DD HH-MM-SS.txt"
   - Compatible with Kubios HRV import (Type 1 format)
   - Reference: https://help.elitehrv.com/article/49-exporting-raw-r-r-intervals

4. KUBIOS HRV (data/demo/kubios/)
-----------------------------------

kubios_hrv_export.txt
   - Source format: Kubios HRV Premium TXT/CSV report export
   - Separator: comma
   - Sections (in order):
     1. Header: software version, date
     2. Data File Information: filename, recording time, RR count, artifacts
     3. Artifact Correction: method and threshold
     4. Time-Domain Results: Mean RR, SDNN, Mean HR, RMSSD, pNNxx, etc.
     5. Frequency-Domain Results: VLF/LF/HF peak, power (ms2, log, %, n.u.), LF/HF ratio
     6. Nonlinear Results: SD1, SD2, ApEn, SampEn, DFA
     7. Autonomic Balance: PNS index, SNS index, Stress index
     8. RR Intervals: raw RR values (one per line, ms)
   - Each results section uses: Variable,Units,Value
   - Validated by presence of "Kubios HRV" string in file
   - Reference: Kubios HRV Users Guide, https://github.com/PGomes92/kubios
